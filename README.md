# Pokedex

### Instruções rápidas:

1) Criar tabela no Postgres (executar no psql):

   psql -d escola -f schema.sql

2) Inserir um Pokémon de exemplo:

   php insert.php

3) Listar todos os Pokémon (CLI):

   php select.php

4) Buscar por id (editar `select_where.php` ou ajustar variável `$id`):

   php select_where.php

5) Atualizar / Deletar (editar `update.php` / `delete.php` e rodar):

   php update.php
   php delete.php
